# Ticketing System Lab
## Overview
hands-on practice with an IT ticketing system to develop skills in ticket creation, troubleshooting, documentation, prioritization, and incident response.
## skills practiced 
- creating and managing support tickets
- Categorizing and prioritizing tickets
- Troubleshooting user issues
- Documenting troubleshooting steps
- Communicating ticket resolutions
- escalating issues when necessary
  ## objective
  Gain practical experience with ticket-based workflows commonly used by IT support and Security operations team.
